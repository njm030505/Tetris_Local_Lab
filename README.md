## 다운로드와 실행

### 실행

1. [Releases](https://github.com/skytree33157/Tetris/releases/latest)에서 `TFSE-0.2.2.zip`을 다운로드하고 **완전히 압축 해제**합니다.
2. 압축을 푼 폴더에서 `TFSE.exe`를 실행합니다.
3. “Windows의 PC 보호” 창이 뜨면 “추가 정보” → “실행”을 선택합니다.

### 삭제

게임을 종료한 뒤 폴더 안의 `uninstall.bat`를 실행하거나 폴더를 통째로 삭제합니다.

**삭제하면 저장된 설정과 점수도 모두 지워집니다.**

## 조작법

### 메뉴

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 항목 이동 |
| Enter | 선택 |
| ← / → | 설정값 변경 |
| ESC | 설정 화면 닫기 / 키 재설정 취소 |

### 게임

| 기본 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 — 누르고 있으면 반복 이동 |
| ↓ | 한 칸 아래로 이동 |
| ↑ | 시계방향 90도 회전 |
| Space | 하드드롭 |
| P | 일시정지 / 재개 |
| ESC 짧게 누른 뒤 떼기 | 게임 중 설정 열기 |
| ESC 1초 이상 누르기 | 프로그램 종료 |

이동·회전 키는 설정에서 변경할 수 있습니다. P·Space는 전용 키이며 ESC는 재설정 취소 키라 조작 키로 지정할 수 없습니다. 같은 키를 여러 동작에 중복 지정할 수 없고, 재설정 도중 ESC로 취소하면 기존 키가 유지됩니다.

일시정지 메뉴에서는 **계속하기 / 시작 화면 / 게임 종료**를 선택할 수 있습니다.

## 기본 게임 규칙

- I · O · T · S · Z · J · L의 7종 테트로미노가 등장합니다.
- 한 행을 채우면 삭제 대상이 먼저 표시되고, 행이 삭제된 뒤 위쪽 블록이 내려옵니다.
- **NEXT**에는 다음 블록이 표시되며, 게임 화면에서 점수·레벨·삭제 줄 수를 확인할 수 있습니다.
- 회전할 공간이 부족하면 좌우 위치를 보정합니다. 보정할 수 있는 공간이 없으면 회전하지 않습니다.
- 블록을 새로 배치할 수 없거나 보드 위쪽 여유 공간에 블록이 남으면 게임 오버가 됩니다.

[보드·조작 테스트와 결과 보기](docs/test-results.md#보드와-기본-조작)

### 레벨과 하강 속도

시작 레벨은 1, 최대 레벨은 10입니다. 처음에는 1초마다 한 칸 내려오고, 블록 고정 수나 삭제한 줄 수가 기준에 도달하면 더 빨라집니다.

| 상승 기준 | 하강 간격 감소량 |
|---|---|
| 블록 10개 고정 기준 | 모든 난이도 100ms |
| 줄 10개 삭제 기준 | EASY 80ms / NORMAL 100ms / HARD 120ms |

두 기준이 같은 블록 고정 시점에 충족되면 레벨은 한 단계만 올라갑니다. 하강 간격은 최소 100ms로 제한됩니다.

[하강 속도·레벨 테스트와 결과 보기](docs/test-results.md#하강-속도와-레벨)

## 모드와 난이도

### 일반 모드와 아이템 모드

| 모드 | 규칙 |
|---|---|
| 일반 모드 | 기본 7종 블록으로 플레이합니다. |
| 아이템 모드 | 기본 규칙에 아이템 5종이 추가됩니다. 누적 10줄 경계를 넘을 때 새 NEXT에 아이템이 공급됩니다. |

아이템은 현재 블록으로 바로 교체되지 않고 **NEXT를 먼저 거칩니다**. 예를 들어 누적 9줄에서 2줄을 지우면 기존 NEXT가 현재 블록으로 이동하고, 새 NEXT에 아이템이 나타납니다.

### 난이도별 차이

새 게임을 시작하기 전에 설정에서 선택합니다.

| 난이도 | I형 상대 가중치 | I형 등장 확률 | 점수 배율 |
|---|---:|---:|---:|
| EASY | 12 | 약 16.67% | ×0.8 |
| NORMAL | 10 | 약 14.29% | ×1.0 |
| HARD | 8 | 약 11.76% | ×1.2 |

다른 6종의 가중치는 각각 10입니다. I형이 20% 더 자주/덜 등장한다는 규칙은 **상대 가중치**에 적용하며, 전체 확률을 합쳐 100%가 되도록 계산합니다.

[블록 생성 확률 테스트·결과 보기](docs/test-results.md#블록-생성-확률-검증) — 반복 횟수·기대 확률·오차 기준·확인된 실행 결과

## 점수와 스코어보드

- 자동 하강: 레벨에 따라 한 칸당 기본 1~5점
- 아래 키 하강: 한 칸당 기본 1점
- 하드드롭: 이동 거리 한 칸당 기본 2점
- 줄 삭제 기본 점수: **1줄 100 / 2줄 300 / 3줄 500 / 4줄 800**
- Bonus: P 한 칸당 **EASY 800 / NORMAL 1,000 / HARD 1,200점** 추가

줄 삭제에는 레벨·콤보·퍼펙트 클리어 조건이 반영됩니다. 난이도 배율은 각 점수 계산의 마지막에 적용하고 반올림합니다.

[점수 상세 규칙과 계산 예시](docs/scoring.md)를 확인하세요.

게임 오버 화면은 최종 점수와 해당 난이도·모드의 TOP 10을 보여줍니다. 순위 조건을 만족하면 이름을 입력받아 저장하고, 방금 등록한 기록을 강조합니다. 기록은 종료 후에도 유지됩니다.

스코어보드에서는 **← / →로 난이도**, **Tab으로 모드**를 바꿔 조회합니다.

[점수 계산 테스트와 결과 보기](docs/test-results.md#점수-계산) · [스코어보드 테스트와 결과 보기](docs/test-results.md#설정과-스코어보드)

## 설정과 접근성

- 화면 크기: 작게 / 보통 / 크게
- 색상 모드: 일반 / 적색맹 / 녹색맹 / 청황색맹

- 스코어보드 초기화
- 기본 설정 복원

블록을 색상과 패턴으로 구분하고 아이템은 문자를 함께 표시합니다. NEXT에서도 같은 표시 방식을 사용합니다.

게임 중에는 난이도 변경과 기본값 복원이 제한됩니다. 저장한 설정은 다음 실행 시 다시 불러옵니다.

## 개발 환경에서 실행

<details>
<summary>JDK 21 · 소스 빌드 · 테스트 안내</summary>

이 절은 개발자용입니다. 배포 패키지의 플레이어는 위의 실행 파일 안내를 사용합니다.

JDK 21을 설치하고 프로젝트 루트의 PowerShell에서 실행합니다. Gradle은 Wrapper가 준비하며 최초 실행에는 다운로드를 위한 인터넷 연결이 필요합니다.

```powershell
.\gradlew.bat classes
java -cp build/classes/java/main app.Main
```

단위 테스트와 커버리지 보고서:

```powershell
.\gradlew.bat test jacocoTestReport
```

| 결과 | 생성 위치 |
|---|---|
| 테스트 보고서 | `build/reports/tests/test/index.html` |
| 커버리지 보고서 | `build/reports/jacoco/test/html/index.html` |

설정된 최소 커버리지 검증:

```powershell
.\gradlew.bat jacocoTestCoverageVerification
```

테스트 수·통과 여부·커버리지는 해당 버전의 실제 실행 결과로 확인합니다. 측정 대상·제외 범위와 검증 기준은 [build.gradle](build.gradle)에 정의되어 있으며, HTML 보고서와 최소 기준 검증의 측정 범위가 다를 수 있습니다.

현재 main의 개발 실행 데이터는 아래 경로를 사용합니다.

- `src/main/java/menu/settings/settings.properties`
- `src/main/java/storage/scores.txt`

프로젝트 루트에서 실행하세요. #77 반영 후에는 개발 실행 데이터가 사용자 홈의 `.tfse/data`로 옮겨지고, 패키지 실행 데이터는 실행 폴더의 `data`를 사용합니다.

</details>

<details>
<summary>실행 파일 제작 — packaging PR 반영 후</summary>


```powershell
.\packaging\buildexe.ps1
```

예정 산출물은 `build/exe/TFSE-0.2.2.zip`입니다. JRE·아이콘·삭제 스크립트를 함께 묶으며 별도 설치 과정 없이 압축을 풀어 실행하는 방식입니다. 스크립트를 다시 실행하면 기존 `build/exe` 산출물을 새로 만듭니다.

</details>
