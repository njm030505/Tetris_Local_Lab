# item 요구사항

## 줄 삭제 아이템
- 줄 삭제 아이템은 기본 블럭 내에 포함되며, 문자 'L'로 나타냅니다.
- 블럭이 더 이상 움직이지 못하게 되면 'L'이 위치한 줄은 해당 줄이 꽉 차지 않아도 삭제합니다.
- 이 아이템이 블럭에 붙는 위치는 무작위로 정해져야 합니다.
- 아이템으로 인해 삭제되는 줄에 대해서도 기존의 방식대로 점수를 계산합니다.

## 무게추 아이템
- 무게추 아이템은 총 4칸의 너비를 지닌 아이템입니다.
- 해당 아이템은 떨어지면서 밑에 있는 모든 블럭들을 지우는 아이템입니다.
- 처음에는 자유롭게 좌우로 움직일 수 있지만 일단 바닥이나 다른 블럭에 닿으면 더 이상 좌우로는 움직이지 못합니다.
- 기본적으로 이 아이템의 사용이나 지워지는 블럭 등에 대해서는 점수를 부여하지 않습니다.
- 추가로, 이 블럭은 회전하지 않습니다.

## 폭탄 아이템
- 폭탄 아이템은 1*1 크기의 블럭입니다.
- 이 아이템이 보드의 고정된 블럭이나 바닥에 닿을 시 이 아이템 주위 3*3 영역을 삭제합니다.
- 이 아이템에 의해 삭제된 블록에 대한 추가 점수는 없습니다.

## 보너스 아이템
- 보너스 아이템은 기본 블럭 내에 포함되며, 문자 'P'로 나타냅니다.
- 이 아이템이 붙는 위치는 무작위로 정해져야 합니다.
- 이 아이템이 포함된 줄이 삭제 시 임의의 보너스 점수를 얻게 됩니다.

## 슬로우 아이템
- 슬로우 아이템은 기본 블럭 내에 포함되며, 문자 'S'로 나타냅니다.
- 이 아이템이 붙는 위치는 무작위로 정해져야 합니다.
- 이 아이템이 포함된 줄이 삭제 시 블럭 하강 속도가 영구히 느려집니다.
- 블럭 하강 속도는 1초보다 느려질 수 없습니다.
- 이 아이템이 포함된 줄이 삭제 시 추가 점수는 없습니다.
