# 아이템 설명

[README로 돌아가기](../README.md) · [점수 규칙](scoring.md)

아이템 모드에서 사용할 수 있는 다섯 아이템의 형태·발동 조건·효과를 설명합니다. 같은 L/P/S라도 원본 블록은 7종 중에서 달라질 수 있습니다.

## 등장 규칙

- 아이템 모드에서 누적 삭제 줄 수가 10줄 단위를 넘으면 새 NEXT에 아이템이 등장합니다.
- 기존 NEXT는 그대로 현재 블록이 되고, 새 아이템은 그다음 차례에 조작합니다.
- L·W·B·P·S는 같은 확률로 선택합니다.
- L/P/S의 원본 테트로미노는 선택한 난이도의 생성 확률을 따릅니다.
- L/P/S는 원본 블록의 **채워진 칸 중 하나**에 무작위로 부착합니다.
- 일반 모드에서는 아이템을 공급하지 않습니다.

본 문서에서의  `·`는 빈칸, `□`는 일반 블록 칸입니다. 부착형의 모양은 설명을 위한 예시이며 고정된 형태가 아닙니다.

## 줄 삭제 L

| 항목 | 규칙 |
|---|---|
| 표시 | 일반 테트로미노 한 칸에 **L** |
| 발동 | L을 포함한 블록이 고정될 때 |
| 범위 | 현재 L 칸이 있는 행 전체 |
| 점수 | 기존 줄 삭제 점수 적용 |
| 회전 | 원본 블록과 함께 회전 |

부착 예시:

```text
□ □ L □
```

해당 행이 덜 채워져 있어도 삭제합니다. L이 있는 행이 일반 완성 행과 겹치면 한 번만 집계합니다. 함께 완성된 다른 행도 삭제 대상에 포함합니다.

**확인 예시:** 비어 있는 칸이 남은 행에 L 블록을 고정합니다. L이 있는 행이 삭제되고 위쪽 블록이 내려오는지, 점수와 삭제 줄 수가 반영되는지 확인합니다.

## 무게추 W

| 항목 | 규칙 |
|---|---|
| 표시 | 은회색·벽돌 패턴의 **W** |
| 모양 | 너비 4칸, 윗줄 가운데 2칸 + 아랫줄 4칸 |
| 발동 | 낙하 중 아래의 고정 블록과 접촉할 때 |
| 효과 | 자신의 너비 아래의 블록을 제거하며 계속 내려감 |
| 좌우 이동 | 첫 접촉 전 가능, 접촉 후 불가 |
| 회전 | 불가 |
| 점수 | 제거 효과 자체는 0점 |

```text
· W W ·
W W W W
```

다른 블록에 닿은 순간 좌우 이동이 잠깁니다. 접촉 후, 아래 블록을 지우며 내려갑니다. 바닥에 도달하면 보드에 남습니다.

제거 효과 자체에는 점수를 주지 않지만, 하강 점수는 별도 규칙으로 계산합니다.

**확인 예시:** 고정 블록 위로 W를 내립니다. 접촉 전에는 좌우 이동이 가능하고, 접촉한 뒤에는 좌우 이동·회전이 되지 않으며 아래 블록이 제거되는지 확인합니다.

## 폭탄 B

| 항목 | 규칙 |
|---|---|
| 표시 | 어두운 배경·둥근 몸체·심지·**B** |
| 모양 | 1×1 |
| 발동 | 더 이상 아래로 내려갈 수 없을 때 |
| 범위 | 폭탄 칸 중심의 3×3 영역 |
| 점수 | 폭발로 제거한 칸 자체는 0점 |

폭발 범위:

```text
× × ×
× B ×
× × ×
```

범위를 애니메이션으로 표시한 뒤 제거합니다. 벽이나 바닥에서는 보드 내부에 있는 칸만 제거합니다.

폭발로 영향을 받은 행이 완전히 비면 그 행을 정리하고 위쪽 행을 내립니다. 이 빈 행 정리는 일반 완성 행 삭제와 구분하며, 자체적으로 줄 삭제 점수·누적 삭제 줄 수를 추가하지 않습니다.

폭발로 P/S 칸을 직접 제거하는 것만으로는 P/S의 행 삭제 효과가 발동하지 않습니다.

**확인 예시:** 고정 블록 옆에 B를 놓습니다. 중심에서 좌우·위아래 한 칸까지 제거되고 범위 밖은 유지되는지 확인합니다. 벽 옆에서도 범위가 보드 안으로 제한되어야 합니다.

## 보너스 P

| 항목 | 규칙 |
|---|---|
| 표시 | 일반 테트로미노 한 칸에 **P** |
| 발동 | 고정된 P가 포함된 행이 삭제될 때 |
| 집계 | 행 개수가 아닌 **삭제된 P 칸 개수** |
| 회전 | 원본 블록과 함께 회전 |

부착 예시:

```text
□ P □ □
```

고정만으로는 점수가 지급되지 않습니다. P가 있는 행을 삭제해야 보너스를 받습니다. 일반 줄 삭제나 L의 강제 행 삭제로 P가 지워지면 지급 대상에 포함됩니다.

| 난이도 | P 한 칸당 보너스 |
|---|---:|
| EASY | 800점 |
| NORMAL | 1,000점 |
| HARD | 1,200점 |

보너스에는 레벨·콤보·퍼펙트 클리어 배율을 적용하지 않습니다. 행을 지운 점수와 별도로 더합니다.

**확인 예시:** NORMAL에서 같은 행의 P 두 개를 삭제하면 보너스는 **2,000점**입니다. 일반 줄 삭제 점수는 여기에 별도로 더해집니다. P 두 개를 한 개로 계산하지 않습니다.

## 슬로우 S

| 항목 | 규칙 |
|---|---|
| 표시 | 일반 테트로미노 한 칸에 **S** |
| 발동 | 고정된 S가 포함된 행이 삭제될 때 |
| 집계 | 삭제된 S 칸 개수 |
| 효과 | S 한 칸당 하강 간격 500ms 증가 |
| 상한 | 하강 간격 최대 1,000ms |
| 회전 | 원본 블록과 함께 회전 |

부착 예시:

```text
□ □ □ S
```

고정만으로는 느려지지 않습니다. S가 포함된 행을 지워야 합니다. S가 여러 개이면 각 칸의 효과를 합산하고 상한을 적용합니다.

| 기존 하강 간격 | 삭제한 S | 적용 후 간격 |
|---:|---:|---:|
| 200ms | 1개 | 700ms |
| 200ms | 2개 | 1,000ms |
| 800ms | 1개 | 1,000ms |
| 1,000ms | 1개 | 1,000ms |

Slow는 레벨을 낮추지 않습니다. 이후 레벨 상승 조건에 도달하면 하강 간격은 다시 줄어들 수 있습니다.

**확인 예시:** 자동 하강이 빨라진 상태에서 S가 있는 행을 지웁니다. 더 느리게 내려오는지 확인합니다. 처음처럼 이미 1초 간격인 상태에서는 상한 때문에 변화가 없습니다.

## 효과와 점수 구분

| 처리 | 일반 줄 삭제 점수 | P 보너스 / S 효과 |
|---|---|---|
| 일반 완성 행 삭제 | 적용 | 그 행의 마커 개수만큼 적용 |
| L의 강제 행 삭제 | 적용 | 그 행의 마커 개수만큼 적용 |
| Bomb의 영역 제거 | 영역 제거 자체는 없음 | 영역에서 직접 제거된 마커는 발동하지 않음 |
| Weight의 아래 칸 제거 | 제거 자체는 없음 | 직접 제거된 마커는 발동하지 않음 |
